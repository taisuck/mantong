# 만통(만사형통)

StockAgent로 수집한 주식 시계열 테이터를 분석하여 전고점 이벤트를 처리하고, 인공지능 모델에 MCP 서버를 제공한다.

차후 집의 IoT 기기 제어, 기념일 관리등 개인적인 잡무 자동화를 기능화 한다.

- 사용 언어 : GoLang

- 클로드 코드를 통해서 개발할 수 있도록 처리했고, 추후 여러 사람이 협업을 할 경우를 대비해서 monorepo가 아니라 각 파츠별로 따로 repository를 구성

- 윈도우나 리눅스에서 동작 가능

- 각 파츠별 문서는 notion에 따로 정의하여 repository와 별도로 관리

- github에 이슈를 등록하고, 이슈 할당을 받으면 개별 브랜치를 발급받아서 업무 진행

- Dockerfile을 두어 배포가 필요한 시점에 가능하도록 처리

- 배포 자동화는 아직..( 배포를 자동으로 할 필요성이 아직 없고, 관련해서 서버가 마련되지 않음 )
